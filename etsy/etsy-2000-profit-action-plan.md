## 1. Market & Product Research (USA & UK)

### 1.1 POD T-shirts: ඇත්ත තත්ත්වය
- Generic slogan tees: **ඉතා saturated.** "Funny cat shirt" වගේ ඒවායින් පටන් ගන්න එපා.
- දිනන්නේ මේ ක්‍රම තුනෙන් එකක් හරි කීපයක් එකතු කරපු listings:
  1. **Personalisation**: නම්, දිනයන්, ළමයින්ගේ නම්, "Est. 2026", hometown. Personalised items වලට **£4–6 premium** එකක් අය කරන්න පුළුවන්.
  2. **Micro-niche + trend**: Gothmas (gothic Christmas), Nutcrackercore, "Nonna" holiday aesthetic, coquette bows, retro/vintage wash designs.
  3. **Identity/Profession**: "Concrete Finisher Dad", nurse, teacher, dog breed + owner name.
- **Comfort Colors 1717** වගේ garment-dyed premium blanks වලට US වල ඉල්ලුම වැඩියි, ඒවට ඉහළ මිලක් දාන්න පුළුවන්.

### 1.2 Differentiation formula
`[Trend aesthetic] + [Personalisation field] + [Specific recipient/identity] + [Occasion]`

උදා: *Gothmas* + *custom name* + *for goth girlfriend* + *Christmas gift*

## 3. Social Media Automation System

### 3.1 Workflow එක (80% automated, සතියට පැය 2–3 ක batch work)

```
[අලුත් Etsy listing එකක්]
      │
      ├──► (A) Etsy Shop RSS feed ──► Pinterest "Auto-publish" (free, native)
      │        etsy.com/shop/<SHOPNAME>/rss
      │
      ├──► (B) Make.com (Etsy module) ── "Watch new listings"
      │        └─► AI step (Claude/ChatGPT): pin titles 5ක්, FB caption, TikTok hook 3ක්
      │              └─► Google Sheet (content bank)
      │
      ├──► (C) Canva Bulk Create (Sheet ──► Pin/Story/Slideshow templates)  ← සතියකට 1 පාරක්
      │
      └──► (D) Schedulers
             ├─ Pinterest  → Tailwind (SmartSchedule + Communities)
             ├─ Facebook   → Meta Business Suite (free) හෝ Buffer
             └─ TikTok     → Buffer / TikTok web scheduler (photo-slideshow + mockup videos)
```

## 4. SEO & Listing Optimisation

### 4.1 2026 Title formula
Etsy දැන් **කෙටි, පැහැදිලි titles** වලට කැමතියි (keyword stuffing නෑ). Title එකේ **මුල් වචන 5–7 බොහොම වැදගත්.**

```
[Item එක මොකක්ද + ප්‍රධාන keyword] + [Personalisation/Differentiator] + [Style/Niche] + [Recipient හෝ Occasion]
```
- අකුරු 70–110 ක් විතර තියාගන්න, එකම වචනය නැවත නැවත දාන්න එපා.
- **Attributes** (colour, occasion, holiday, recipient) සම්පූර්ණයෙන් fill කරන්න. ඒවා tags වගේම search එකට වැදගත්. ඒ වචන tags වල නැවත දාන්න ඕනේ නෑ.
- Description එකේ මුල් වාක්‍ය 1–2 ට ප්‍රධාන keyword එක ස්වභාවිකව එකතු කරන්න.
